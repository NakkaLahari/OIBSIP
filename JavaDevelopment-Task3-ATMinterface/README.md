# ATM Interface

A console-based ATM application developed using Java. It allows users to perform basic ATM opeartions.

## Features
- User login
- Account balance checking
- Cash withdrawal
- Cash deposit
- Transaction management

## Technology Used
- Java ( Object - Oriented design with multiple classes )
