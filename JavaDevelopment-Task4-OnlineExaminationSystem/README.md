##Online Examination System

##Project Description

The Online Examination System is a Java-based application that allows students to attend online examinations. Students can log in, answer multiple-choice questions (MCQs), and complete the examination within a specified time limit.

The system includes a timer and automatically submits the exam when the time runs out.

##Features

- Student Login
- Multiple Choice Questions (MCQs)
- Timer-based Examination
- Automatic Submission
- Score Calculation
- Result Display

##Technologies Used

- Java
- Java Swing (GUI)
- VS Code
